## 🚀 Run Locally

You can easily run this portfolio on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/zainab-naeem-20/Personal-Portfolio-website.git
```

### 2. Open the Project Folder

```bash
cd Personal-Portfolio-website
```

### 3. Launch the Website

Open `index.html` in your preferred browser.

For a better development experience, use the **Live Server** extension in Visual Studio Code.
